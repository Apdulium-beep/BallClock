# Android-контроллер BallClock 1.8

Android 8.0+ (API26), target35, package `local.ballclock.controller`, versionCode9.

Актуальный APK — [в корне проекта](../../BallClock-1.8.apk),
старые версии — [в релизах](https://github.com/Apdulium-beep/BallClock/releases).
[Сборка и ключ подписи](../../docs/BUILD.md#android).

Приложение управляет часами по локальному HTTP API, автоматически запрашивает
сеть BallClock и показывает реальные кадры с часов. Изображение не стримится
с телефона: сохранённые эффекты воспроизводятся на самой плате.

Вкладки: циферблат, свет, время, рисование, сеть. Рисование имеет отдельный
большой холст: вертикально сверху, горизонтально слева с инструментами справа.
При повороте используется тот же WebView, черновик и история сохраняются.

Настройки, до8 именованных градиентов и до8 картин хранятся в часах.
Поддерживаются кисть, выделение, пипетка, заливка, масштабирование, перемещение,
отмена штрихов и независимые эффекты/скорость/фаза каждого из128 шариков.
Цвет выбирается внутри панели; отдельное системное окно не открывается.

Код и сетевые проверки в `tests/`; общая HTML-панель — `assets/mobile.html`.
Этот HTML также используется генератором при последующей сборке прошивки.
Готовая прошивка с рисованием совместима с APK1.8 без новой перепрошивки.

Физическая установка/поворот на конкретном устройстве требуют пользовательской
проверки. Безопасность локального API и ограничения платформы — в корневом README.
