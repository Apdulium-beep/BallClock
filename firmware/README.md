# Прошивка BallClock · ESP8266 / Wemos D1 mini

128 адресных GRB-светодиодов, DIN -> D5/GPIO14, датчик освещённости -> A0.
Ленте нужен отдельный подходящий источник 5В; GND платы и ленты общий.

Сборка из корня: `pio run --project-dir firmware`, либо `build-firmware.cmd`.
Версии платформы/библиотек закреплены в `platformio.ini`.
[Подробности сборки и загрузки](../docs/BUILD.md).

`firmware.bin` — готовая проверенная прошивка с рисованием. Android1.8 меняет
компоновку приложения и совместим с ней. Готовый BIN содержит предыдущую
встроенную веб-панель; следующая сборка встроит актуальный общий HTML из
`source/android/assets/mobile.html`. Файл `tools/page.html` — историческая
панель и больше не является входом генератора.

## Работа

- USB115200, протоколv3; локальный HTTP APIv1, описание в `../api/`.
- Открытая точка BallClock / `192.168.4.1`, без роутера и интернета.
  В режиме роутера точка остаётся включённой; прямой режим не сканирует сети.
- Вывод ленты: FastLED с разрешёнными прерываниями между пикселями,
  ручным масштабированием яркости и ограничением тока. Настройки в `src/config.h`.
- Время, шрифты, цвета, фон/градиенты/Перлин, датчик и ночной режим.
- До8 именованных градиентов и до8 картин со128 независимыми эффектами.
- Файлы LittleFS: `/settings.txt`, `/art0.txt` ... `/art7.txt`.
  Сохранение через временный файл и атомарное переименование.

После закрытия клиентов плата работает автономно, пока получает питание.
После полного обесточивания без батарейного RTC нужна синхронизация времени.
Не выполнять полное стирание flash/загрузку пустой LittleFS, если нужны старые данные.

## Важные исходники

`main.cpp` — цикл, USB, время, вывод; `render.cpp` — общий рендер;
`geometry.cpp` — физический порядок128 LED; `artcodec.h`/`art.cpp` — картины;
`settings.cpp` — параметры/градиенты; `net.cpp`/`web.cpp` — сеть/API.
Шрифты основаны на данных AlexGyver/BallClock, см. `NOTICE-BallClock-MIT.txt`.

Ночной режим намеренно отключает фон/рисунок. Wi-Fi открытый, HTTP без
авторизации/шифрования: только доверенная локальная сеть, без публикации порта.
