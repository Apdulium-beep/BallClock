# BallClock

**Прошивка ESP8266 и контроллер часов для Windows.** Android-приложение — рядом,
в этом же репозитории; все сохранённые APK доступны в отдельных релизах.

### Начать работу

**На ПК:** распаковать **весь** Windows ZIP и запустить `launcher.exe` либо
`qt_app/BallClockController.exe`. Один EXE без DLL и плагинов недостаточен.
Выбрать USB/COM-порт или Wi-Fi/IP. Готовый комплект также находится в этом
репозитории: лаунчер в корне, зависимости и контроллер — в `qt_app/`.

**На Android:** установить APK 1.8, открыть приложение, разрешить запрошенный
доступ к Wi-Fi и подтвердить подключение к `BallClock`. Интернет не требуется.
Для обновления устанавливать новый APK поверх старого, не удаляя приложение.

**Часы:** ESP8266EX / Wemos D1 mini, 128 адресных светодиодов, DIN на D5/GPIO14,
датчик освещённости на A0. Ленте нужен подходящий отдельный БП 5 В и общий GND.
Первичная сеть — открытая точка `BallClock`, адрес `192.168.4.1`.

## Возможности

- Управление по **USB и локальному Wi-Fi**, сохранение параметров в часах.
- ПК формирует кадры через общий с прошивкой рендер и отправляет их на часы;
  Android показывает кадры с часов и не требует постоянной передачи изображения.
- Шрифты и цвет цифр, однотонный фон, градиенты, палитры, шум Перлина.
- Визуальный выбор цвета, до **8 именованных пользовательских градиентов**.
- **Рисование:** 128 независимых шариков — цвет, выключение, плавное переливание
  или мигание; собственные цвета, период и сдвиг анимации у каждого пикселя.
- До **8 картин в памяти часов**, необязательный слой времени поверх рисунка.
- В Android 1.8 — отдельная вкладка «Рисование»: вертикально холст сверху,
  горизонтально холст слева и инструменты справа. Поворот не перезагружает редактор.
- Яркость, датчик освещения, ночной режим, синхронизация времени с ПК/телефона/NTP.

После отключения приложения часы продолжают работать **пока есть питание**.
После полного выключения без батарейного RTC время нужно синхронизировать заново.

## Совместимость и ограничения

Готовая прошивка и ПО ПК содержат режим рисования; Android 1.8 меняет интерфейс
и совместим с этой прошивкой без новой перепрошивки. Готовый BIN содержит
предыдущую встроенную веб-панель; APK использует собственную актуальную панель.
При новой сборке прошивки веб-панель генерируется из общего HTML в исходниках.

Ночной режим намеренно отключает фон, в том числе рисунок. Для слоя времени
поверх картины нужен включённый шрифт. Начните с медленного мигания, если оно
вызывает дискомфорт.

**Безопасность:** точка доступа открытая, HTTP без шифрования и авторизации.
Использовать только в доверенной локальной сети. Не открывать порт часов в интернет.

Проверены сборки, модульные тесты, интерфейс в браузере, USB-управление,
автономная анимация и сохранение картин после аппаратного сброса. Окончательная
проверка установки и поворота APK 1.8 на конкретном телефоне/планшете остаётся
за пользователем; непрерывная связь при любых аппаратных/системных сбоях не гарантируется.

## Структура

```text
firmware/              прошивка, PlatformIO, готовый firmware.bin
source/qt_app/         исходники приложения Windows и общего рендера
source/launcher/       исходники Windows-лаунчера
qt_app/                готовое приложение Windows с DLL и плагинами
source/android/        Android и общая HTML-панель управления
BallClock-1.8.apk      актуальный Android APK
api/                   HTTP API и OpenAPI
licenses/              лицензии и уведомления сторонних компонентов
docs/                  сборка и история APK
```

Архивные релизы содержат **подлинные сохранённые APK**, а не заново собранные
исторические версии. Их теги указывают на первоначальный публичный снимок
исходников, а не на восстановленную историю разработки каждой старой версии.

Основано на [BallClock от AlexGyver](https://github.com/AlexGyver/BallClock).
Уведомления об авторстве и лицензии исходного проекта сохранены.
